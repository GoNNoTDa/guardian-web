Privacy Policy

Last updated: July 2026

Guardián Web is a defensive extension designed around the principle of minimal data collection. Here's exactly what it does with your information.

What data it handles and where

DataWhere it livesDoes it leave your device?
Per-tab risk signalsSession memory (cleared on close)No
Warning history, trust list, settingsBrowser local storageNo
Local copy of the malware feedLocal storageNo (download only)
Data you type into formsOnly in the page's own memoryNever stored or sent

Queries to external services (optional)

Except in local mode, the extension may make these queries, all for your security:

  • Community reputation (sec.fourmartech.es): while browsing, only a hash prefix of the domain is sent (k-anonymity). The server never knows which specific site you're visiting.
  • Google Safe Browsing / URLhaus: only if you configure your own API keys.
  • URLhaus malware feed: periodic download of a public list; it includes no data about you.

Local mode, which you can enable in the options, disables all these queries: nothing leaves your device.

Community reports

  • Sent only when you manually click "Report this site." Nothing automatic.
  • An anonymous, random installation identifier is used, stored hashed on the server.
  • No email, account or IP address is stored: a report contains only the domain, the category and the date.

What Guardián Web does NOT do

  • Does not collect or sell browsing data.
  • Does not use analytics or telemetry.
  • Does not inject ads or alter content (except the warning banner).
  • Does not create accounts: there is no email, name or profile tied to you.
  • Does not download or run remote code: only the code shipped in the package runs.
  • Freshly installed and with no API keys, it sends nothing to any server.

Permissions it does NOT request

What it doesn't ask for matters as much as what it does. Guardián Web declares no cookies, history, bookmarks, clipboardRead, identity or nativeMessaging permission: it technically cannot read your session cookies, your browsing history, your bookmarks or your clipboard, nor talk to programs on your machine. The full list is in the repository's manifest.json.

How to delete your data

There is no account to close because none is ever created. The warning history is cleared from the popup itself; the trust list, settings and API keys from the options page. Uninstalling the extension wipes all of its storage at once.

This website

This page uses no cookies, no analytics and no third-party fonts or scripts: it's static HTML and CSS. Like any web server, it receives the IP address of incoming requests in order to answer them; it is never cross-referenced with extension data or used to identify anyone.

Open source

All the code is public and auditable under the MIT license. You can verify for yourself exactly what the extension does.
