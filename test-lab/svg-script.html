🖼️ Prueba: SVG con JavaScript

Esperado en esta página: gráfico SVG con código (+45) y SVG externo que puede ejecutar código (+45) = 90 → banner naranja.

Inofensiva: el único script de un SVG que hay aquí escribe un texto dentro del propio gráfico. El SVG «externo» apunta a un dominio .test que no existe, así que no se carga nada.

1) SVG en línea con código dentro (+45)

2) SVG de otro dominio cargado con <object> (+45)

Cargado así, el SVG sí ejecuta su código. El dominio no existe, así que no verás nada: la señal viene del cómo, no del qué.

3) El adjunto: un SVG abierto como documento (+70)

Abrir malicious.svg — es el caso de los adjuntos que se multiplicaron por cincuenta en un año. Ábrelo y mira el panel lateral allí: debe salir «Esta imagen trae código».

Controles que NO deben disparar nada

a) SVG en línea sin código (un icono normal)

b) El mismo SVG con código, pero cargado como imagen

Con <img> el navegador no ejecuta el script del SVG, así que no hay nada que avisar.

c) SVG del mismo origen con <object>

Mismo dominio: no es un tercero, no se marca.
